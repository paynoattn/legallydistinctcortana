# Read-aloud voice and clipboard

Preconditions: Windows 11 with speakers or headphones. A Wyoming Piper server is reachable, for example `docker run -p 10200:10200 rhasspy/wyoming-piper --voice en_US-amy-medium` on a machine on your LAN or tailnet. The app runs with `VOICE_HOST=<that machine> make dev` (add `VOICE_TTS_PORT` if the port is not 10200, and `VOICE_TTS_VOICE` to change the server default voice). Nothing else uses Ctrl+Alt+R. Reading itself (the reader, moods, pausing, following) is in [focus-reader](focus-reader.md).

1. Select text and press Ctrl+Alt+R. Click the voice button in the reader's control bar. → Expect: the voice picker opens with your system language selected and Voice on "Server default". Set Language to a different language and Voice to one of its voices. → Expect: the current sentence starts again in that voice, and the voice button shows its name. Press Esc, select text again, and press Ctrl+Alt+R. → Expect: it reads in the chosen voice, and the picker opens with the same language and voice still selected. If the server has a multi-speaker voice (for example `en_US-libritts-high`), choose it. → Expect: a Speaker list appears with "Default speaker" first, and the chosen speaker is the one you hear. Set Voice back to "Server default" when done.
2. Copy the word "original" to the clipboard. Select a sentence in Notepad, press Ctrl+Alt+R, and press Escape. Paste with Ctrl+V. → Expect: the reader closed, and "original" is pasted, so the clipboard was restored.
3. In File Explorer, copy a file (Ctrl+C). Select a sentence in Edge, press Ctrl+Alt+R, and press Escape. Paste into a folder. → Expect: the file is pasted, so every clipboard format was put back. If the reader instead says the clipboard was left untouched, paste still works the same way.
4. Stop the Piper server. Quit the app and start it again with the server still stopped, then select text, press Ctrl+Alt+R, and click the voice button. → Expect: the voice picker says "Voices are unavailable: …" with a Retry button. Start the server and press Retry. → Expect: the voice picker fills in.

Cleanup: restart the Piper server if you stopped it. The voice, the last mood, and the text size are stored in the read-aloud window's local storage; setting Voice to "Server default" removes the voice.
