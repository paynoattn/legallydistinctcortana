# Read selected text aloud in a mood

Preconditions: Windows 11 with speakers or headphones. A Wyoming Piper server is reachable, for example `docker run -p 10200:10200 rhasspy/wyoming-piper --voice en_US-amy-medium` on a machine on your LAN or tailnet. The app runs with `VOICE_HOST=<that machine> make dev` (add `VOICE_TTS_PORT` if the port is not 10200, and `VOICE_TTS_VOICE` to change the server default voice). Nothing else uses Ctrl+Alt+R.

1. Open a long article in Edge. Select a paragraph and press Ctrl+Alt+R. → Expect: a small dark window opens next to the mouse pointer, inside the screen, showing the start of the paragraph, its length in characters, a voice picker with your system language selected and Voice on "Server default", and nine moods with Neutral highlighted.
2. Press 2. → Expect: the window shows "Reading in a calm voice." and the paragraph is read slower and softer, starting within about a second. When it ends, the window closes by itself.
3. Select text, press Ctrl+Alt+R, set Language to a different language and Voice to one of its voices, then press 1. Select text again and press Ctrl+Alt+R. → Expect: it reads in the chosen voice, and the window opens with the same language and voice still selected. If the server has a multi-speaker voice (for example `en_US-libritts-high`), choose it. → Expect: a Speaker list appears with "Default speaker" first, and the chosen speaker is the one you hear. Set Voice back to "Server default" when done.
4. Copy the word "original" to the clipboard. Select a sentence in Notepad, press Ctrl+Alt+R, and press Escape. Paste with Ctrl+V. → Expect: the window closed, and "original" is pasted, so the clipboard was restored.
5. In File Explorer, copy a file (Ctrl+C). Select a sentence in Edge, press Ctrl+Alt+R, and press Escape. Paste into a folder. → Expect: the file is pasted, so every clipboard format was put back. If the window instead says the clipboard was left untouched, paste still works the same way.
6. Select a paragraph in Word, press Ctrl+Alt+R, move down with the arrow keys to Mad, and press Enter. While it reads, press Ctrl+Alt+R. → Expect: louder, faster speech that stops immediately on the second press.
7. Select a paragraph, press Ctrl+Alt+R, choose Alert, then click into another app while it reads. → Expect: the window hides and the reading continues; Ctrl+Alt+R stops it.
8. Click an empty area of the desktop so nothing is selected and press Ctrl+Alt+R. → Expect: the window says "Select some text first, then press the read-aloud shortcut." with a focused Close button; Escape closes it.
9. Stop the Piper server. Select text, press Ctrl+Alt+R, and choose Neutral. → Expect: the window shows "can't reach the voice server at <host>:<port>: …" in the alert colour and nothing is read. Quit the app and start it again with the server still stopped, then select text and press Ctrl+Alt+R. → Expect: the voice picker says "Voices are unavailable: …" with a Retry button. Start the server and press Retry. → Expect: the voice picker fills in.
10. Move the mouse to the bottom-right corner of a second monitor (if you have one), select text there, and press Ctrl+Alt+R. → Expect: the window opens up and to the left of the pointer, fully on that monitor.

Cleanup: restart the Piper server if you stopped it. The voice choice is the only thing stored (in the read-aloud window's local storage); setting Voice to "Server default" removes it.
